Custom Gift Card Visual
=======================

This module customizes the visual layout of gift cards in Odoo 18
loyalty reports by replacing the default header container with a
centered Coop'Cinelles picture.

**Table of contents**

.. contents::
   :local:

Usage
=====

Once the module is installed, gift card reports generated from
``loyalty`` automatically display the custom centered visual instead of
the default block.
